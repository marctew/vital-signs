Home Assistant

Vital Signs can announce every Pi and display to Home Assistant through the MQTT broker Home Assistant already uses. They appear there as devices by themselves: online status, screen on and off, the playlist, what is showing, page problems, the Pi's temperature and power, and buttons for Identify, Reload, Next and Previous. Nothing needs configuring in Home Assistant.

Status: {{ status }}

Leave the prefix as homeassistant unless you changed it in Home Assistant's MQTT settings. Use the same broker address and login that your other MQTT devices use.

For alerts, import the blueprints in the repo's homeassistant/blueprints folder into Home Assistant, or build automations on the entities yourself. If this server stops, Home Assistant shows every Vital Signs entity as unavailable.
